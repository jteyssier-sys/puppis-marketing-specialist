## 📞 En Caso de Problemas

**Script no ejecuta:**
```bash
chmod +x *.sh  # Dale permisos
```

**Git falla:**
```bash
git config user.name "Tu Nombre"
git config user.email "tu@email.com"
```

**Sed no funciona en macOS:**
```bash
# macOS necesita sed -i '' (con comillas)
# Linux: sed -i (sin comillas)
```

**Si todo falla:**
1. Descargá ZIP manualmente
2. Adapta nombre de cliente manualmente (búsqueda + reemplazo)
3. Haz git init, commit, push manualmente
